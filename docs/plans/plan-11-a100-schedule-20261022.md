# plan-11 · 32×A100 排期：scaling 补点 + 蒸馏分组学生（2026-10-22）

口径不变：固定 epoch；E3 末 60 个 val 窗口；同机同 seed nogram 配对；ΔVal = nogram − arm。耗时按 H200 实测 ×3 估 A100（**估**，首批实测后修正）。

## 显存边界（决定什么能上 A100-40GB）

exact/hash 表 ≈ 20 B/表参数（§134 实测）。50M 档：每阶 R ≤ 400k（R/N ≤ 8）或 multi-head 400k 行可上 A100；R/N ≥ 16 的 50M 和任何 104M+ exact 只能留 H200。nogram 臂任何档都可上 A100（104M nogram ≈12 h）。蒸馏学生 4 深度可训练表 2.56B 参数 ≈41 GB → 只上 H200；A100 跑 depth-0 版（640M）。
