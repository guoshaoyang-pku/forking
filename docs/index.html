Sudden Overfitting Under Replay

In language models with local n-gram memory, replay can drive training loss down while held-out loss rises. We study when this split appears, which predictions are hurt, and how it relates to continuation coverage.

ReproduceEvidence & codePaper figures

What we find

  1. The divergence follows replay. Separation grows as training revisits the finite corpus.
  2. A seen context can have an unseen continuation. Improved fitting of observed continuations can coexist with worse predictions for plausible alternatives.
  3. Continuation coverage organizes the gap. Three-seed frequency-bin measurements support an approximate relationship between novelty and the online gap.

These findings motivate evaluating memory-augmented models across repeated passes, beyond their initial improvement in fitting.

Reproduce the analysis

Clone the release branch, then run two standard-library checks:

git clone --branch release --single-branch https://github.com/guoshaoyang-pku/forking.git
cd forking
python3 reproduce/verify_coverage.py
python3 reproduce/verify_contexts.py

Python 3.10 or newer. No packages, GPU, or model download are needed for these checks. They recompute eight coverage fits and check 72 context endpoints from the bundled observations.
