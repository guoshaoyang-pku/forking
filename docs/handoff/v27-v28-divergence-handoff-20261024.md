## 2. 学习率与组合修复不能统称成功

实际表学习率=主干学习率×表学习率倍率。旧实验将主干从6e-4降至3e-4但不改倍率，同时减半了表学习率，不能归因为“只降主干”。学习率减半没有吞吐减半的证据。

35M、数据比例80、seed43、三遍56,966步，在同机 `a100_t1_4`：
- 两组学习率同时降低：`v27_35m_exact_r280k_dn80_tls0.5_s43_e3_p27b_lr0.0003_fixed`，验证loss最低2.935992，最终6.594295，末60点6.648023。进程正常退出，但科学上失败。
- 只降主干、保持原表学习率：`v27_35m_exact_r280k_dn80_tls1_s43_e3_p27b_lr0.0003_fixed`，最终2.654931，末60点2.656090。同机无表 `v27_35m_nogram_r280k_dn80_tls0.5_s43_e3_p27b_lr0.0003_fixed` 为2.733336，配对差−77.246 mnat/token。
- 17M结果也依赖表规模：小表seed43只降主干仍退化，较大表seed43联合降学习率也退化。不能从一个健康长训推广为通用修复。

50M、数据比例56、seed43，两条加表降学习率实验均已完成56,966步，最终loss为2.542257（联合降低）和2.545594（只降主干）。对应无表尚未结束，不计算完整配对收益。run_id为 `perm/v27_50m_exact_r400k_dn56_tls{1,2}_s43_e3_p27b_lr0.0003_fixed`。

组合修复v28同时改变动量、裁剪、预热和学习率日程。50M本对现在已成功收尾，但17M/35M已有无表失败反例，因此不能称统一修复。仅裁剪在原50M长训晚期失败的历史判决保留（§150）。旧S2学习率seed42配对位于借出的 `a100_t1_3`，本轮不访问、不以旧进度冒充新结果。

## 3. 机制结论与旧数字的修正

“注意力logit失控先于loss恶化”以及归一化干预支持尺度失控解释。但第一层闲置是否为必要原因、句首注意力集中是否为中介、不同规模是否共享唯一机制，尚无充分的独立干预证据。归一化含可学习参数，不能声称logit永远有界。

原版长训差值−63.8、−51.6、−27由不同步数末值相减，撤出正式收益表。原版“零发散、不伤nogram”“三条稳定线”“过旧onset即终判”“学习率减半速度减半”均撤回。是否完成必须看注册终点，性能必须看同机完整配对。原版104M数据包络及学生蒸馏读数来自§150，保留历史证据身份，本轮不将它们升级为新复核结论。
