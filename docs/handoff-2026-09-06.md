## 1. 已固化的核心结论（按证据链组织）

### 1.1 主现象（权威数值，128× 标准，2k 步，seed 42，`§47`）

| 臂 | final train | final val | **final gap** |
|---|---|---|---|
| **input** | 1.221 | 6.435 | **5.214** |
| y | 1.073 | 7.537 | 6.464 |
| v | 1.114 | 6.930 | 5.816 |
| nogram | 5.785 | 6.030 | 0.245 |

- run：`nglab1x_{input,y,v,nogram}_v5_128x_freq10_fd_fixed`；种子 43/44 复现 5.42/5.53，结论稳健（§32）。
- fork 发生在 epoch 边界（337/675 步）；train loss 每 pass 内骤降、val 不动或升 → gap 锯齿增长。

### 1.2 因果干预（`causalv5m2/m3`，128×，§38/§45；reset_table/mask_readout 已删除不入册）

- **hash_reseed**（只换 context→row 映射，保留表权重/优化器 state）：单边界 gap 几乎清零；e1+e2 双边界 0.069 → **内容与 key 的绑定是 gap 的必要条件**。
- **mask_high f≥t**（14 点阈值扫描，§35.8.1）：t=200 峰值 2.824，t≥100 平台 ~2.75，t≤25 急降，t=2 最低 1.752；t=1 回升 1.927（novel f=0 context 从不被 mask）。**高频 context 的贡献可忽略，gap 主体来自中低频**。
- **freeze_table@e2 保留 94% gap**（5.386 vs 5.733 @2022）；freeze_table@e1@1000 甚至 gap 更大（3.452 vs 2.724）；**freeze_backbone@e1 → 1.585**（§38）。→ gap 的持续增长在 backbone 侧，表 pass 1 后的变化对 gap 无关。

### 1.3 动力学分解（§48–§50，当前理论主线）

**「pass」精确定义**：对固定 train shard 的第 e 次完整顺序遍历（1x=337 步，batch 顺序每 pass 相同）。

1. **增长位置（§48）**：72% 的 gap 增长发生在 pass **内部**（连续漂移），边界跳变只占 28% 且随 pass 衰减。「逐 pass 写入」被证伪。
2. **不饱和（§48/§42）**：20ep 长 replay 的 net gap 从 e5 起**线性**（0.664/pass，R²=0.9976）；单指数/平台模型全部失败。
3. **谁在被伤害（§48/§42 blrabs）**：三条 backbone LR 的 train_benefit 在 pass~10 饱和于 ≈2.5 且完全重合；**晚期增长 100% 是 val_penalty**（携带全部 LR 依赖）——margin/logit-scale 持续放大的指纹。
4. **pass 数不是独立变量（§48 判决⑤）**：固定 pass ⇒ gap 对 LR 仅 ~η^0.18 且 ≥1e-3 饱和；固定 dose ⇒ 低 LR 更大。统一解释：「每步增量 h(η) 随 η 饱和、对 **step** 累加」。gap 是 step 累加量，不是 dose 累加量。
5. **覆盖率是原罪，训练动态是放大器（§49）**：val 伤害 d_e(f)/M_f 在 f∈[2,320) 两个数量级内**恒定**（CV 4–6%，pass≥3）——不存在「见得少更偏执」；M_f（Good-Turing 缺失质量，1x shard 整体 0.278）决定 f 形状，训练只贴全局幅度 A_e（+2.10 nats/pass 线性）。val 伤害 pass 1 已存在（无重复时）。
6. **表不是一次写完，且与 gap 无关（§50）**：cos(row@e1,row@e6)：bigram 0.52(低频)→0.76(高频)，trigram ~0.57；每 pass 相对写入是纯尺度参考的 3–6 倍 → 持续真实重写（RMSProp 无衰减下的惯性滑行），但 freeze 实验证明这对 gap 无关紧要。
7. **gap 增长 = novel-token 抑制动力学（§50，backbone 驱动）**：
   - margin（logit[train-dominant cont.] − logit[true novel tok]）随 pass 线性增长：f=1 桶 1.57→6.97（**+1.08/pass**）；**freeze_backbone@e1 后 margin 增量 −76%（f=100 完全平）**。
   - 传递系数封闭验证：d(loss)/d(margin)=1−p̂_novel≈0.87；实测 novel loss +0.94/pass ≈ 1.08×0.87 ✓（无自由参数）。
   - 三项分解（pass1→6 变化）：novel 抑制 Δin=+5.8(f=1)→+3.6(f≈400)（唯一 f 依赖项）；seen 退化 ≈ 常数 +1.1（f≥13；f≤2 掉到 ~0，记忆保护 dip，**不是 1/f**）；机会成本（nogram 基线改善未获得）≈ 常数 −1.5~−2.0、f 无关。
   - **环境门控发现**：f=1 的 seen val token（train 里记到 loss≈0 的 (c,x) 对），input 模型在 val 环境 loss=4.6 nats（p≈0.01），远差于 nogram 1.17 → **记忆只在 train-like 环境调出**，pass 1 时该伤害已 +2.29。
8. **理论修正点**：H-KAPPA 的 seen 侧 V·min(S_eff,f)/f 项预测低频伤害增大，与实测（低频保护 dip + 平坦）冲突，需改为「常数退化 + 低频保护」。

### 1.4 优化器/LR 消融（128× 选定依据，§30–§33）

- table LR 扫描：step-1000 gap 峰值在 ×128（~2.73），×16 未饱和、×256/512/1024 不更优且趋不稳；β₂=0.99 vs 0.999 无差异 → 选 0.99。warmup_constant 与 constant 差异小，统一用 warmup_constant(100)。
- backbone LR：6e-4 为 v5 选定（blrabs 批锁定绝对 table LR 后扫，§42）。

### 1.5 三轴 scaling（§40/§44/§46 等，128× 重刷后）

- **table-size**：gap–R 双对数在中段近似幂律（bigram slope ~0.43 / trigram ~0.66；外推猜测 1/2、2/3，未证实）；低端（R≤1e4）噪声大（novel 基线未减），高端 R≥3e5 表多空行偏离线性。
- **epoch 长度**：按 L4 倍数排 10+ 点，3 epoch 窗口；gap 随 epoch 数线性（见 §48）。
- **frequency**：主实验 freq-bin 双轴 + gap-vs-frequency（fd 口径）。
- hash collision：R=2²⁰ 下 bigram/trigram 均零碰撞（§46 离线实测）。

## 2. 测量基础设施（改动口径须新 run_id）

- **fast-diag（标准）**：诊断 forward bf16 autocast + 异步 CPU worker 聚合（`code/diag_worker.py`，`NGLAB_ASYNC_DIAG=0` 回退）；eval block ~1.5s（旧 ~21s）；等价性单测通过（searchsorted==dict、异步==同步）；训练动态与旧 fp32-diag 逐位同分布（§47 四臂曲线重叠验证）。`_fd` 与旧后缀曲线不混画单条。
- **诊断语义**：freq_bin/exact_freq 的 train 侧 = 当前 batch 的 per-token loss 复用（不取新 batch）；val 侧 = 4 个 fixed batch；online train loss 更新前记录、fixed-val 同 step 更新后。
- **replay 分析设施（新）**：`docs/plot_scripts/analyze_v5_table_cosine_decomp.py` 逐位同序 replay 任意权威 run，pass 边界快照表权重 + val 上 seen/novel/margin 分解；产物在 `data/runs_theory/<run>_snap/`（集群 19GB 表快照 + decomp.jsonl，本地 /tmp 有 decomp 副本）。后处理 `analyze_v5_cosine_margin_posthoc.py`、图 `plot_v5_table_cosine_margin.py`。

## 5. 一句话理论现状

> 表提供私有 key 使 train 集对 backbone 可分 → backbone 在归一化优化器下以恒定速率锐化「认出 context → 输出 train continuation」的映射（margin 线性增长，wd 是唯一反向力）→ val 上占 ~28% 的 Good-Turing novel token 被持续压低（gap 增长主项，~60%），seen 侧常数退化 + 机会成本构成其余 ~40%；数据侧形状（M_f）冻结不变，幅度随 step 线性。epoch 结构只通过泄漏开启时刻 + 28% 边界刷新进入。
