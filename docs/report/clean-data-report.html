2. Shard dose 扫描（M5 · v2 · 2000 步）

shard dose = 训练集大小相对标准 1× 训练集（≈50M unique tokens）的比例。曲线横轴为训练 step（1 step = 147,456 tokens），dose 是曲线参数。双对数坐标下，小 dose 的过拟合/泛化分叉与大 dose 的平坦区被同时展开。

图 2 · 曲线簇（log–log）：左 train loss、中 val loss、右 gap，每个颜色 = 一个 dose（图例给出实际 unique token 数）。同色竖直虚线 = 该 dose 完成一遍训练集的 epoch 边界。0.25× 在双对数下 train loss 直线下降（幂律过拟合）、val loss 与 gap 直线上升；≥2× 各线贴底平坦。8× 为 1870 步部分数据。
图 3 · Meta 关系（log–log）：固定 step=500/1000/2000 采样，train/val/gap 对 shard dose 的依赖。gap 面板拟合幂律 gap ∝ dose^α：α(500)=−2.12、α(1000)=−2.29、α(2000)=−1.76 —— 三个采样点斜率一致（≈−2），说明 gap 对 dose 的响应在新标准下是稳定幂律。非正 gap 在 log 轴上剔除。
图 4 · 固定 step 2000 的 dose–response：左 log-x 全景（含负 gap），右双对数（symlog 保留近零区）+ 正 gap 幂律拟合。◇ = 部分 run（8×, 1870 步）。gap 从 0.25× 的 16.3 单调下降到 ≥4× 的 ≈0：新标准不改变 dose 响应方向，只抬升整体水平并加陡斜率。
图 5 · Bigram 分 bin（v2 · skill 规范双轴图）：左轴 = token fraction 分组柱（train #2d6f9f / val #c4493d，含 novel）；右轴 = 各 bin 平均 loss + 最终 per-bin gap（#353d79 点线，novel 处断开）。train 侧为 online 窗口：每次评估从独立诊断迭代器新取 4 个 train batch（不消费训练流），与 val 的 fixed 窗口对齐。低频 bin 的 val−train gap 最大：gap 集中在低频区。
图 6 · Trigram 分 bin（v2）：同图 5 结构。trigram context 更稀疏，novel/低频 bin 占比更高，per-bin gap 绝对值更大、随频率衰减更陡。
图 7 · Gap vs frequency（log-x + log-log 双面板）：最终 per-bin gap 对 context 频率（几何中点）。log-log 下近似幂律 gap ∝ f^α（α<0）——「gap 是低频现象」在 v2 新标准下依然成立。非正 gap 已剔除（图内注明）。

6. 口径说明

  • 历史新标准 v2：表优化器 RMSProp 无动量 β=(0.0, 0.99)、table_lr_scale=2.0、bf16（本波次附带 torch.compile；当前默认标准已改为 table_lr_scale=128.0、backbone lr=0.0006 且不 compile，见 agents.md §1）；backbone AdamW、lr 0.004 仅作本历史波次坐标。
  • train loss 口径 = online：所有主图与表格的 train loss 都是当前训练 batch 的 loss（与 fixed val 同一 step 记录），即 agents.md 规定的 online gap 主测量。freq-bin 图的 train 侧是 online 窗口：每次评估从独立诊断迭代器新取 4 个 train batch，不消费训练流。
  • gap 定义：val_loss − train_loss，同一 step、同一 fixed-val batch；novel context 无 train loss，不进 gap。
  • 双对数规范：gap ≤ 0 的点在 log 轴上剔除（图注说明）；dose–response 右面板用 symlog 保留近零与负值区域。
  • 部分数据：A2/A1/A4 主体已全部完成；e6 批与 freeze/ρ/表大小补点仍在三机队列消费中，完成后回填。
