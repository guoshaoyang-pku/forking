夜间读数：发散靠主干梯度裁剪可治，蒸馏表去均值后反超无表基线

今晚定了四件事。训练池里有三片数据是另一片的原样拷贝，已剔除。所有健康之外的发散都能被主干网络的梯度裁剪消除。forking 代价主要由表大小决定，数据量只能缓解一部分。蒸馏表此前的落后来自每阶共有的均值偏置，去掉之后从第 500 步起就领先无表基线。

四条支线：scaling 与蒸馏两条今晚各出一个判决

v2 主线：消除 forking 的危害，保留 n-gram 注入（OE）的收益
支线 0 · 机制已发表结题。
支线 1 · scaling(D/N, R/N) 二维面已出首读；发散原因找到；104M/200M 补点在跑。
支线 2 · 消除危害梯度裁剪治发散（初读 5/5）；forking 频率分解给 gate 设计提供靶点。gate 由合作者在跑。
支线 3 · 蒸馏表去均值后反超无表基线；层视图扫描 4 臂与对照 8 臂在跑。

名词：OE 指把 n-gram（n=2~5）查表结果加到模型输入嵌入上的结构，每阶一张表。forking 指重复训练时训练 loss 继续下降而验证 loss 停滞或回升。gap 等于同一 step 的验证 loss 减训练 loss。ΔVal 是 OE 相对无表基线的验证集收益，正数表示 OE 更好，它是验收标准。ΔVal 恒等于 Δtrain（训练 loss 压低多少）减 Δgap（gap 比基线多多少，即 OE 额外带来的 forking）。单位 mK 等于 0.001 nat。N 是模型参数量，D 是不重复训练 token 数，R 是每阶表的行数。

训练池里三片数据是另一片的原样拷贝，已剔除

9 个注入臂的发散起点都挤在第 16,500–16,770 步，跨越 35M 到 200M 和不同表大小。这一窗口里无表基线的训练 loss 同样骤降约 0.3 nat。逐片比对 32-token 片段哈希后发现：第 60、62、63 片的采样片段 100% 与第 1 片相同，其余 144 片都不超过 2%。凡训练池超过 2.385B token 的配置，都在第一遍中段把第 1 片原样再学一遍。三片已从清单移除，14 个受影响的臂已停，重跑带 _p27b 标签。2.385B 以下的所有读数不受影响。

发散来自主干网络的梯度尖峰，裁剪主干梯度后全部平滑越过原发散点

剔除重复片之后仍有 11 个真发散臂，分布在不同的表大小与数据量上，无表基线一个都没有。原配方只裁剪表的梯度。新增一个默认关闭的主干梯度范数裁剪（阈值 1.0），原样复跑 5 个发散臂：其中 3 个已越过原发散点，验证 loss 平滑下降，另 2 个尚未到达。健康对照在同一时刻的验证 loss 没有变差。

需要等第 3 遍末与裁剪版无表基线配对，才能确认裁剪对净收益的影响。若确认无损，主干梯度裁剪应进入默认配方。

forking 代价主要由表大小决定，数据量只能缓解一部分

在 35M 与 50M 两档上把表大小 R/N 与数据量 D/N 交叉扫描。代价项 Δgap 可以写成 A·(R/N)a·(D/N)b，三组拟合的 a 在 0.85–1.04，b 在 −0.30 到 −0.60。若代价只取决于每行分到的 token 数 D/R，应有 a=−b。实测 |a| 明显大于 |b|，所以每行 token 数不是充分变量：表加倍时代价几乎加倍，数据加倍只把代价压低 20–35%。

档Δgap 拟合点数
50M，表学习率 1 倍25·(R/N)1.04·(D/N)−0.3419
35M，表学习率 0.5 倍17·(R/N)0.85·(D/N)−0.3017
35M，表学习率 1 倍46·(R/N)0.86·(D/N)−0.6013

同一位置上表学习率减半，代价约缩小为 1/2.7，所以表学习率是第三个独立的调节量。沿数据量单轴看，指数衰减比幂律拟合得更好，两种形式都不支持存在一个降不下去的代价下限。此前口头汇报的 Δgap∝(D/N)−0.5 用的是包含后来判为发散点的末点口径，以本节为准。

forking 不集中在低频 context，没有被表覆盖的位置也在 fork

用第 3 遍末逐 token 的 loss 记录，按 context 在训练池中的出现次数分组，再按该位置最深被哪一阶的表覆盖分组。数据量充足（D/N=20）时，四阶的代价在出现 100 次到 10 万次之间大致持平，没有越稀有越 fork 的幂律。数据量小时代价整体抬高，峰值落在出现 10–100 次的 context 上。

D/N=20，R/N=8：最深覆盖阶位置占比ΔValΔgap
无任何表覆盖15%−25+35
2 阶46%+21+58
3 阶23%+34+66
4 阶9%+39+101
5 阶7%+61+130

覆盖越深，收益越大，代价也越大。没有任何表覆盖的位置，gap 也比基线大 35 mK，验证集变差。这部分代价不在表行上，而在主干网络：表接管了局部条件后，主干在其他位置也更依赖训练集。由此可以推出，按频率屏蔽表行只能削掉表行上的代价，碰不到这 15% 位置上的外溢，这与此前「低频 mask 在 n=2~5 联合下不管用」的观察一致。可检验的分工：主干侧手段（裁剪、正则）应主要压低无覆盖位置的代价，表侧 gate 应主要压低 4–5 阶的代价。

等比放大：第一遍收益随模型变大而增大，第 3 遍末的净收益在变薄

固定 D/N=20、R/N=8，只改模型大小。第一遍末净收益从 35M 的 +55~60 升到 104M 的 +77 mK，代价接近零。到第 3 遍末，50M 的代价已涨到 +69~73 mK，净收益只剩 +22~28。104M 和 200M 的第 2、3 遍读数今天上午到下午陆续落地。

蒸馏表的落后来自每阶共有的均值，去均值后从第 500 步起就领先

蒸馏表用 Qwen3.5-4B 的残差在 10B token 上聚类得到，每阶 250 万行、64 维，经一个零初始化的投影加到学生模型输入上。原始蒸馏值在第 1000 步落后无表基线约 970 mK，此后缓慢追近，同等幅度的随机表几乎不落后。原始值里有一个每阶共有的均值方向，占能量约 40%。减去这个均值并缩放回原幅度后，第 500 步即领先基线 +120 mK（第 1–8 层视图）到 +290 mK（第 25–32 层视图）。越深的层视图领先越多。

还不能下结论：早期领先在衰减（A100 上去均值可训练臂从第 300 步的 +270 降到第 1000 步的 +80）。它能否保持到第一遍末（约第 7355 步，今天上午）和第 3 遍末（明天），决定蒸馏表是否成为学生模型的默认初始化。
